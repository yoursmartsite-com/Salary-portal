# FIELD GUARD

نظام أولي لإدارة حضور وانصراف وجولات عمال الملاعب.

## المعاينة
بعد النشر على GitHub Pages:
https://yoursmartsite-com.github.io/Salary-portal/field-guard/

## الحالة الحالية
هذه نسخة واجهة تفاعلية أولية. بيانات العمال والحركات والجولات تحفظ محلياً في متصفح الجهاز باستخدام localStorage، ولا تتم مزامنتها بين الأجهزة.

## قبل التشغيل الفعلي
- إنشاء مشروع Firebase مستقل لهذا النظام (لا يعاد استخدام قواعد بيانات مشاريع أخرى).
- تفعيل Authentication وحسابات منفصلة للمشرف والعامل.
- إعداد Firestore Security Rules بحيث لا يستطيع العامل تعديل سجلات الحضور أو حذفها، مع صلاحيات المشرف عبر claims موثوقة.
- تنفيذ تسجيل أحداث الحضور والانصراف بوقت الخادم، والتحقق من الموقع ونطاق النادي في جهة موثوقة.
- إضافة رفع صور إثبات مباشرة وسياسة احتفاظ وموافقة واضحة.
- إضافة إشعارات FCM وجولات تفتيش بمهلة واستجابة موثقة.
- اختبار تزوير الموقع والأجهزة الحقيقية قبل اعتماد النظام كسجل دوام.

لا تستخدم نسخة المعاينة كدليل حضور رسمي.
