# لَمّة — Godot Social World

مشروع مستقل لإعادة بناء عالم HUB بمحرك Godot 4.7، مع الحفاظ على نسخة الموقع الحالية إلى أن يكتمل التصدير والاختبار.

## الموجود في البداية
- مشهد ثلاثي الأبعاد جديد.
- شخصية بنت كرتونية ناعمة الملامح بدل شكل Roblox المكعب.
- كاميرا منظور ثالث وحركة أساسية وقفز بلوحة المفاتيح.
- ساحة ليلية، ممشى، شاطئ، بحر، أشجار، أعمدة إنارة، عجلة ملاهٍ وكافيه.
- زر قفز على واجهة المشهد.

## التشغيل
افتح هذا المجلد في Godot 4.7 ثم شغّل المشهد scenes/world.tscn.

## ملاحظات
هذه قاعدة أولية وليست النسخة النهائية. نموذج الشخصية الحالي مبني إجرائيًا داخل Godot، وسيتم ترقيته إلى موديل 3D عالي الجودة مع Rig وحركات حقيقية قبل ربط Firebase وتصدير نسخة الويب.
لن يتم استبدال hub.html الحالي قبل نجاح التصدير والاختبار على الهاتف.
