# لَمّة — Godot Battle Lobby

مشروع إعادة بناء مستقل لعالم HUB بمحرك Godot 4.7، مع الحفاظ على نسخة الموقع الحالية دون استبدالها قبل التصدير والاختبار.

## الموجود حاليًا في ملفات المشروع
- لوبي ثلاثي الأبعاد بطابع معسكر معركة: مدرج، حظائر عسكرية، أبراج مراقبة، صناديق إمداد، حواجز خرسانية وجبال خلفية.
- واجهة لوبي داخل Godot مع الاحتفاظ بتحكم الهاتف واللاعبين المتصلين.
- شخصية بنت 3D احترافية (Casual Woman) بصيغة GLB، شعر وملابس وخامات PBR، مع Rig وأنيميشن Walk/Run؛ يتم تنزيل أصل CC0 تلقائيًا أثناء بناء نسخة الويب.
- كاميرا منظور ثالث تتبع اللاعب.
- تحكم لوحة مفاتيح، وعصا لمس مرئية للحركة على الهاتف، وسحب يمين الشاشة لتحريك الكاميرا.
- زرا الجري والقفز على الشاشة.

## التشغيل
افتح مجلد المشروع في Godot 4.7 وشغّل المشهد `scenes/battle_lobby.tscn`.

## ما لم يكتمل بعد
يوجد اختبار آلي للمشهد واختبار لإنشاء شخصية لاعب بعيد ومزامنة موقعه. جودة الموديل والأنيميشن تحتاج مراجعة بصرية على الهاتف بعد النشر. المشروع ما زال نسخة أولية وليست تسليمًا نهائيًا. تم استبدال الشخصية الإجرائية بموديل Casual Woman المرخّص CC0 من Grab3D (مجاني للاستخدام والتعديل التجاري والشخصي). ينزّل GitHub Actions نسخة GLB ذات الـRig وأنيميشن المشي والجري قبل الاستيراد والتصدير؛ لذلك لا يحتوي المستودع على نسخة GLB الثنائية مباشرة. ربط Firebase ومزامنة اللاعبين مضافان في نسخة الويب، لكنهما يحتاجان اختبارًا فعليًا بحسابين على الهاتف للتأكد من صلاحيات قاعدة البيانات وسلاسة الحركة. لا يتم استبدال `hub.html` الحالي قبل نجاح الاختبار النهائي.
