# OMNIX GUARD
تطبيق أندرويد تجريبي مساعد لمراجعة بعض مؤشرات الأمان.

## البناء
يُبنى تلقائيًا عبر GitHub Actions من مسار المشروع. ملف APK الناتج هو نسخة Debug للتجربة.

## حدود الحماية
- فحص الروابط محلي ومبدئي ولا يستخدم قاعدة بيانات تهديدات.
- فحص التطبيقات يعرض بعض الصلاحيات المعلنة ولا يفحص ملفات APK بحثًا عن برمجيات خبيثة.
- معلومات الشبكة لا تكشف الاختراق أو التجسس.
- استمر في استخدام Google Play Protect وتحديثات أندرويد.
