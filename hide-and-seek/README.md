# اختبئ أو اهرب — نموذج لعب مستقل

هذه صفحة مستقلة معزولة عن الصفحة الرئيسية وألعاب لَمّة الحالية.

## التشغيل
- افتح `index.html` عبر خادم HTTP أو استضف المجلد على GitHub Pages.
- يحتاج اتصال إنترنت لتحميل Three.js ونموذج الشخصية من CDN.
- يبدأ اللاعب كمختبئ، ويطارده باحث يتحرك بالذكاء الاصطناعي.
- إجمالي الشخصيات الظاهرة في الجولة: 8 (اللاعب + 7 مختبئين آليين + الباحث). ملاحظة: هذا الإصدار يحتوي 8 خانات لعب مقصودة في HUD، لكن التنفيذ الحالي ينشئ اللاعب و7 مختبئين وباحثًا واحدًا؛ لذلك إجمالي المجسمات 9. يجب حسم تصميم الأدوار قبل النسخة النهائية.
- الحركة: WASD أو الأسهم على الكمبيوتر، وعصا لمس على الهاتف. زر E أو «اختبئ» للتخفي بجوار ساتر.

## حدود النسخة الحالية
- هذا نموذج لعب محلي ضد شخصية باحث آلية، وليس أونلاين.
- لا توجد غرف أو مزامنة بين 8 أجهزة، ولا نظام حسابات أو Firebase في هذا المجلد.
- نموذج الجندي التجريبي من Three.js وليس شخصية EMA. لا يتم استبدال شخصية لَمّة أو ربط هذه الصفحة بالموقع الرئيسي.
- البيئة مبنية هندسيًا داخل Three.js؛ لم يتم بعد إدخال حزمة أصول سينمائية خارجية أو إتمام تحسين الأداء على أجهزة أندرويد.
- لم يتم دمج الصفحة في التنقل الرئيسي. يلزم اختبارها على جهاز فعلي قبل أي دمج.

## المرحلة التالية
استبدال نموذج الشخصية بأصل مرخص ومتحقق منه، إضافة أنيميشن اختباء/زحف/قفز، وتحويل الجولة إلى أونلاين حقيقي عبر خدمة غرف/إشارة مناسبة، ثم اختبار 8 عملاء متزامنين.
