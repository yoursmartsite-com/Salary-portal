# فكرتك | FAKRETAK

تطبيق مستقل لاستقبال طلبات تطوير التطبيقات والمواقع والمتاجر والألعاب، مع لوحة إدارة خاصة بمالك المنصة.

## رابط التطبيق بعد النشر
https://yoursmartsite-com.github.io/Salary-portal/developer/

## الوظائف الحالية
- واجهة عربية RTL بتصميم أسود وذهبي.
- نموذج عام لاستقبال طلبات المشاريع.
- حفظ الطلبات في Firestore داخل المجموعة `developerRequests`.
- دخول إدارة بالبريد وكلمة المرور عبر Firebase Authentication.
- لوحة خاصة بمعرّف المالك المحدد في ملف التطبيق.
- عرض الطلبات وتغيير حالتها: جديد، تم التواصل، قيد التنفيذ، مكتمل، مرفوض.

## مطلوب قبل التشغيل الفعلي
1. دمج هذا التغيير إلى `main` حتى ينشر GitHub Pages مجلد `developer`.
2. في Firebase Console > Firestore Database > Rules، أضف المقطع الموجود في `FIRESTORE-RULES-SNIPPET.txt` داخل كتلة `match /databases/{database}/documents` الحالية، ولا تستبدل بقية القواعد.
3. تأكد أن حساب المالك الذي ستستخدمه لتسجيل الدخول هو نفس حساب Firebase Authentication المرتبط بمعرّف المالك الموجود في ملف التطبيق.
4. اختبر إرسال طلب تجريبي ثم افتح دخول الإدارة وتأكد من ظهوره وتغيير حالته.

## ملاحظات
- لم يتم تعديل ملفات تطبيق العطور.
- الموقع لن يستقبل الطلبات بنجاح قبل إضافة قاعدة Firestore الجديدة ونشرها.
- إعدادات Firebase الحالية مشتركة مع مشروع Firebase الخاص بتطبيق العطور، لكن الطلبات محفوظة في مجموعة مستقلة باسم `developerRequests`.
- لا تضع كلمة مرور الإدارة داخل الكود أو في المستودع.
